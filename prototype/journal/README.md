# 日记类型 · 低保真原型（v3）

对应 [issue #3](https://github.com/pipi32167/Silvics/issues/3)。v1 把日记做成了结构化字段（`sections[].items[]`），模块段落里加不进内容 —— v2 改成「日记就是一份 Markdown 文本」。

## 怎么看

```bash
cd prototype/journal
python3 -m http.server 8791
# 打开 http://127.0.0.1:8791/index.html
```

- 纯静态、零依赖、零构建。
- 种子数据，点击结果存 `localStorage`，右上角「重置」回到初始状态。
- **「今天」固定 2026-11-24**，否则种子日期会漂。
- 快捷键 `⌘⇧J` / `⌘⇧T` / `⌘P`（浏览器可能抢 `⌘⇧J`，面板里都有按钮）。

## v3 的形态（Typora 式混合模式）

- 单栏，**默认「所见即所得」**：光标所在行显示源码（`## 工作`、`- [ ] a`、`[[目标]]` 原样），
  其他行渲染成标题、复选框、可点链接。离开该行后自动渲染。
- 另一档「源码」：整篇一份纯文本，用来对照与排查。
- 勾选复选框 = 改源码里那一行，不引入第二份状态。
- 「边界用例」按钮一键跑 49 条自动用例；9 条输入法/撤销类用例标为人工。

用例库与移植说明见 [`docs/日记编辑器边界用例.md`](../../docs/日记编辑器边界用例.md)。

## v2 的形态（已被 v3 取代）

**日记 = 一份 Markdown 文本**，和概念笔记同构；**模块 = `##` 标题**；模板只在新建时注入骨架，之后随便改，不做校验。

- 单栏，可在「源码 / 预览」之间切换。
- 源码模式：整篇是一份纯文本，**任何位置都能直接打字**（v1 的 bug）。
- 预览模式：同一份文本的渲染视图。`##` 变标题、`- [ ]` 变可勾的框、`[[ ]]` 变可跳的链接。
- 勾选复选框 = 改源码里那一行文本（`[ ]` ↔ `[x]`），不引入第二份状态。

## 已定的五条

| 决定 | 在原型里看哪里 |
| --- | --- |
| 承接来自「上一个有日记的日子」 | 新建弹窗的承接预览写明来源日期；11-22 故意没有日记，用来验证不是「昨天」 |
| 承接段标来源 | 正文里的 `## 承接（来自 11-23）`，预览里来源日期标橙 |
| 日记的 `[[ ]]` 计入连接图 | 在日记里写 `[[稀疏重复优于集中突击]]`，再看概念笔记的反向链接 |
| 日记不参与提及扫描，给开关 | 右栏「未链接提及 → 日记参与提及扫描」 |
| 模板是模块段落，也就是 `##` 标题 | 新建弹窗勾「工作 / 生活」，正文预填 `## 工作` `## 生活` |

另外两条 v2 才定的：

- **单栏可切换**源码 / 预览，不做双栏。
- **承接插在光标处**，不强制插到文首；按钮可反复调用，靠标题文本判重。
- **不做软校验**：删掉 `## 生活` 不会提示，模板只是一次性脚手架。

## 哪些是假的

- Markdown 只认三种语法：`##` 标题、`- [ ]` / `- [x]`、`[[ ]]`。加粗、列表缩进、代码块都不渲染。
- `[[` 补全、撤销栈、自动保存、光标行进提示的真实行为：不做。
- git 同步、vault 写入：不做。日记沿用现有 vault 与同步机制。
- 日历、提醒、周报、移动端：不做。

## 仍需你定的一个

**承接块要不要自动带分隔空行？** 现在光标前不是空行时会补一个，避免标题贴在上段正文后面。如果你更想要「严格插在光标处、一个字符都不多加」，我去掉补空行。
